# Zeylun Hospitality — Homepage prototype

Responsive, static HTML/CSS/JavaScript homepage inspired by the approved visual concept.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit http://localhost:8000.

## Deploy
Upload this directory to a static host such as Vercel (Framework Preset: Other, Output Directory: `.`), Netlify, or Cloudflare Pages. Do not replace the live site until you've reviewed it.

## Before launch
- Replace external Unsplash image URLs with licensed, locally hosted hotel imagery and optimize them.
- The contact form currently opens the visitor's email client; connect a backend/form provider for reliable form submissions.
- Review all marketing copy and ensure it accurately reflects available products.
- Add privacy policy, analytics, and genuine case studies when ready.
- Replace the text wordmark with the approved exact wordmark asset if needed.
